# ML-from-scratch

A small collection of Jupyter notebooks that implement basic machine learning algorithms from first principles. These notebooks are meant for learning and experimentation—each one shows step-by-step calculations and simple visualizations.

What you'll find

- Multiple_Linear_regression.ipynb — Complete worked example of multiple linear regression, from normal equations to evaluation.
- Softmax_regression.ipynb — Multiclass logistic (softmax) regression with intuitive explanation and plots.
- linear regression simulation.ipynb — A compact simulation showing how linear regression behaves with noise and sample size.
- logreg.ipynb — Binary logistic regression implemented and visualized.

Why this repo

If you prefer to understand algorithms by building them, these notebooks walk through the math and the code without relying on heavy libraries. They're useful for learning, teaching, or preparing small demonstrations.

Quick start

1. Clone the repo:

   git clone https://github.com/KhushiKeswani/ML-from-scratch.git
   cd ML-from-scratch

2. Open a notebook (recommended: JupyterLab):

   jupyter lab

3. Run the cells in order. The notebooks are self-contained and include small synthetic datasets where needed.

Notes

- No heavy setup required; common packages like numpy, matplotlib and pandas are used.
- Files are intentionally short and focused—feel free to reuse parts for your own experiments.
